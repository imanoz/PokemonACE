# 🥷 Ninja

This script is a combination of [SuperSpeed+](https://github.com/imanoz/PokemonACE/tree/main/Mechanics/%5BP%5D%20SuperSpeed%2B) and a simple walk through wall script when pressing button B.


###  ⚠ Warnings
- The constant effect is achieved using OAM DMA manipulation, which keeps the script running in the background. If you are already using this method, installing the script will overwrite it and break any existing functionality.
- Due to its nature, this script cannot survive a game reset. You will need to activate it again.
- Simple walk through walls script means that you can easily go outside of current map, giving an instant crash and a possible savegame corruption. For this reason, you are advised to use [Ninja+ script](https://github.com/imanoz/PokemonACE/tree/main/Mechanics/%5BP%5D%20Ninja%2B) instead!
